# infinityhomes.vn — static mirror

Bản sao tĩnh (HTML/CSS/JS/ảnh) của https://infinityhomes.vn, tải ngày 2026-11-25.

Chạy thử (phải chạy ở thư mục gốc repo vì link dạng `/wp-content/...`):

```bash
python3 -m http.server 8000
```

Mở http://localhost:8000/home.html (EN) hoặc http://localhost:8000/vi/home.html (VI).

Không hoạt động trong bản tĩnh: giỏ hàng, thanh toán, tìm kiếm, bộ lọc sản phẩm, form liên hệ
(các link này vẫn trỏ về site thật).
